This repository uses two licenses because software and research materials have
different reuse conventions.

## Apache License 2.0

The root `LICENSE` file applies to software source code, tests, executable
scripts, Dockerfiles, Kubernetes manifests, configuration files, and other
materials whose primary purpose is to build or operate the software. The SPDX
identifier is `Apache-2.0`.

## Creative Commons Attribution 4.0 International

The root `LICENSE-DATA` file applies to original documentation, prose, research
datasets and records, workload and forecast traces, tables, and figures whose
primary purpose is to communicate or support the research findings. The SPDX
identifier is `CC-BY-4.0`.

When redistributing CC BY material, attribute it to **Anfa Majid**, identify
the artifact title, link to the repository and license where practicable, and
indicate whether changes were made.

## Exceptions and dependencies

A file-level notice or documented upstream license overrides this directory-
level description. Third-party packages and container base images are not
relicensed by this repository; their respective upstream licenses continue to
apply. The repository references dependencies rather than vendoring their
source code.
