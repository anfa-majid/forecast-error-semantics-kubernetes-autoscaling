# Step 19 Final Analysis Package

Run `tools/analyze_step19_campaign.py` with the bundled Python runtime to regenerate all prospective summaries, comparisons, audit records, plots, validation, and checksums from the immutable campaign results.

The final interpretation is in `ROBUSTNESS-AND-VALIDITY-REPORT.md`. The earlier `OFFLINE-ROBUSTNESS-REPORT.md` remains the source for the 142-run offline sensitivity results and should be retained alongside this package.

The processor reads the Step 19 source campaign without modifying raw evidence.
